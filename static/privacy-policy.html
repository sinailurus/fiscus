Fiscus 隐私政策

更新并生效日期：2026 年 11 月 27 日 · 适用版本 v1.1.0 及之后

Fiscus 是自托管的信用卡卡包工作台。您使用本工具录入的全部卡片、账单与权益数据，均保存在您自己部署的 Fiscus 实例所在的服务器或 NAS 上，Fiscus 项目开发者不运营任何云端服务，也无法访问您的实例。 该实例的部署者（通常就是您本人，或为家人朋友搭建实例的那个人）是实际的数据处理者。 如果您是他人部署实例的使用者，请同时向该部署者确认数据的管理方式。

本政策说明 Fiscus 各项功能处理个人信息的目的、方式、范围，以及您查询、导出和删除这些信息的途径。

一、运营者基本情况与联系方式

  • 软件开发者与发布者：sinailurus（个人开发者，非企业主体）。
  • 注册/办公地址：个人开发者远程开发，无企业注册地址或固定对外办公场所。
  • 投诉、举报与问题反馈：通过 GitHub Issues 提交并跟踪处理进度。
  • 自托管实例运营者：若 Fiscus 由其他组织或个人部署（例如家人朋友替您搭建），实际的数据控制主体以该实例部署者公示的信息为准。

二、基本业务功能与必要信息

Fiscus 不设账号注册体系，没有用户表、不收集邮箱注册信息。唯一可选的身份认证是部署者通过 环境变量配置的一把访问密码：密码为空时鉴权关闭（纯内网使用），设置密码后网页访问需要登录。 因此本工具不存在"注册 / 登录才提供必要信息"的环节，您录入的卡片与账单数据本身就是您主动写入自己服务器的业务内容。

各项功能所需的配置（访问密码、端口、数据目录）均由部署者在部署时决定，详见仓库 README 的「配置说明」。

五、信息的存储、传输与安全

  • 存储位置：全部业务数据保存在您部署实例的服务器 / NAS 本地（data/ 目录，SQLite 数据库 + 图片文件），Fiscus 项目方没有任何服务器参与存储。
  • 传输安全：部署者若通过反向代理（如 Nginx、Caddy、CDN 隧道）提供 HTTPS，登录与数据传输即受 TLS 保护；Fiscus 自身响应带 X-Content-Type-Options、X-Frame-Options、Content-Security-Policy 等安全响应头。纯 HTTP 内网访问不经公网传输。
  • 认证安全：密码比对采用常数时间比较，防时序侧信道；会话 Cookie 为 HMAC-SHA256 签名、HttpOnly、SameSite=Lax；签名密钥文件权限 0600。
  • 上传安全：图片仅接受 PNG / JPG / WebP 并校验文件头，拒绝 SVG 上传以杜绝存储型 XSS。
  • 您的责任：自托管部署者应妥善保管服务器访问权限、部署配置（环境变量或应用安装向导）中的密码配置与 data/ 备份；若实例暴露公网（如走隧道），请务必设置访问密码。导出的备份包含全部业务数据，请妥善保管。

任何网络服务都无法保证绝对安全。如发现异常访问，请立即更换访问密码。

六、您的权利与数据删除

  • 查询与更正：在应用内随时查看、编辑任何一张卡片、一条账单与设置。
  • 导出：数据备份 = 拷贝实例的 data/ 目录（数据库 + 全部图片），或使用应用内备份功能导出备份包。
  • 删除单项数据：在应用内删除对应卡片、账单、图片或清空某项配置，立即生效。
  • 彻底删除：停止容器后删除整个 data/ 目录，即物理删除该实例的全部数据，无法恢复。Fiscus 项目方不持有任何副本。
  • 作废会话：更换访问密码后重新登录即可。

注意：删除实例数据不会影响您已导出的备份包，请按需自行处理。

七、未成年人保护

Fiscus 是面向个人与家庭理财场景的效率工具，不专门面向未成年人提供服务，也不会主动收集任何访问者的年龄信息。 未成年人应在监护人同意和指导下使用。

八、投诉、举报与争议处理

您可以通过 GitHub Issues 提交投诉、举报、隐私相关请求或安全问题。 请勿在公开 Issue 中粘贴访问密码、SMTP 授权码或完整卡片数据。 与您所用实例相关的数据请求（如他人部署的实例），应优先联系该实例的部署者。

九、政策更新

本政策可能随功能变化而更新，更新后的版本将标注日期并随源码仓库发布。 涉及个人信息处理规则的重要变化，会在仓库 Releases 说明中提示。
